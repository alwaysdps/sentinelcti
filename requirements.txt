# Root requirements for the Vercel Python runtime.

# Vercel reads this file to build the functions in /api.
#
# WHY THIS DUPLICATES backend/requirements.txt
# --------------------------------------------
# The obvious approach -- `-r backend/requirements.txt` -- fails the build:
# Vercel's parser does not support requirement-file includes and errors with
# "could not parse requirements.txt". So the list is inlined here.
#
# Duplication invites drift, so `tests/test_serverless_deploy.py` asserts the
# two files declare the same packages. Change one, and the suite tells you to
# change the other.
#
# uvicorn is intentionally omitted: Vercel supplies the ASGI server, so a
# standalone one would only add cold-start weight.
